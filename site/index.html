Pain & Solution, in the Same Place

Port Tools does not replace the CLI and OS utilities developers already rely on. It connects the missing project context between them.

OWNERSHIP

“What project owns port 4178?”

Follows process ancestry and working directories back to the repository, branch, Git worktree, and nearest application manifest.

GROUPING

“Why are there four node processes for one repo?”

Groups applications by repository checkout and separates openable Web pages from background supporting services.

ROUTING

“The port changed again.”

Assigns a persistent address such as phone-studio.localhost (or :17890 without the helper), so you never memorize random dev ports.

SAFE STOP

“Can I safely kill this old server?”

Shows a reviewed stop plan, revalidates PID identity before SIGTERM, confirms listeners released, and refuses Docker or shared runtimes.

One Local Workflow & Narrow Guardrails

The native SwiftUI menu-bar app talks to a bundled Go core over a private, owner-only Unix socket—keeping scanning, probing, routing, and Safe Stop self-contained on your Mac.

01
Discover

Scan live HTTP/HTTPS listeners without changing how your app was started.

02
Identify

Match process trees and cwd to Git repo, worktree, manifest, and page title.

03
Name

Assign and persist a clean *.localhost route atomically across restarts.

04
Open or Copy

Jump straight to the page or copy either the alias or original :port URL.

05
Stop Safely

Revalidate target PIDs, send SIGTERM, and verify the socket was released.

IPC BOUNDARY

Native SwiftUI + Bundled Go Core

Communicates over a 0600 owner-only Unix socket (runtime/core.sock inside a 0700 directory). No Python, Node.js, Homebrew, or external proxy needed at runtime.

PORT-FREE HELPER

Loopback-Only :80 Forwarding

Optional SMAppService LaunchDaemon binds only 127.0.0.1:80 and [::1]:80 and forwards solely to 127.0.0.1:17890, falling back cleanly if busy or unapproved.

SAFE STOP

Single-Use Plan & Refusal Policy

Docker, other-user, shared-runtime, and unattributed listeners are refused. Only unmanaged owned services ignoring SIGTERM can trigger the 3-second red SIGKILL sheet.

V1.0.6 FOOTPRINT

Quiet Idle Scanning

Stops re-probing already-classified live listeners, backs off HTTP 501 responses, batches process inspection, and runs background refreshes on a 5-minute cadence.

v1.0 Scope & Deliberate Boundaries

  • macOS 14 Sonoma or later; public Release builds target Apple Silicon (arm64).
  • Loopback-only IPv4/IPv6 proxy—no accounts, telemetry, or public tunnels.
  • Zero /etc/hosts edits, zero trusted local CA installation, and no port 443 HTTPS listener.
  • Ordinary routing uses :17890; port-free *.localhost requires one System Settings approval.
